# 🎵 Music Player App (Android - Kotlin)

## 📱 Overview

This is a simple and user-friendly **Music Player App** developed using **Android Studio (Kotlin)**.
The app allows users to play songs, control playback, and manage their favorite tracks.

---

## ✨ Features

* ▶️ Play / Pause songs
* ⏭️ Next & Previous controls
* 🎚️ SeekBar for song progress
* ⏱️ Display current time & total duration
* ❤️ Add / Remove Favorite songs
* 🖼️ Dynamic album cover background
* 🔁 Auto play next song
* 🔙 Back button navigation

---

## 🛠️ Tech Stack

* **Language:** Kotlin
* **IDE:** Android Studio
* **UI:** XML Layouts

---

---

## 🚀 How to Run

1. Clone the repository
2. Open in Android Studio
3. Let Gradle sync
4. Run on Emulator or Real Device
